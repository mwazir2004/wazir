# Ridgeline Field Notes (test site)

A static GitHub Pages site for testing: 75 HTML pages, 48 photos (one JPEG each), 8 videos (one MP4 each).
All media is generated by `generate.py`, so it is unique and has no copyright issues. Each asset carries a small ID in its corner (e.g. `RFN-3-03`, `RFN-V02`).

## Publish (no build needed, `docs/` is prebuilt)
1. Create a new public repo on GitHub.
2. Push this folder to the `main` branch.
3. Repo **Settings > Pages > Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, Folder = `/docs`. Save.
4. After about a minute the site is at `https://<user>.github.io/<repo>/`.

All links are relative, so it works both as a project site and as `<user>.github.io`.

## Rebuild / scale up
Needs Python 3.9+, Pillow and ffmpeg on PATH (Windows: `winget install Gyan.FFmpeg`).
```
pip install pillow
python generate.py --out docs --images-per-gallery 20 --base-url https://<user>.github.io/<repo>
```
`--base-url` only affects `sitemap.xml` and `robots.txt`.

## Media patterns covered
- `<img>` with native `loading="lazy"`
- JS lazy-load (`data-src` swapped by `assets/js/lazy.js`) with `<noscript>` fallback (journal posts)
- CSS `background-image` (home hero inline style, last image in each journal post)
- `<video>` with a single MP4 `<source>` (video pages, journal posts, video index tiles)
- `og:image` / `og:video` meta tags, direct download links
- `sitemap.xml`, `robots.txt`, `404.html`, `.nojekyll`
